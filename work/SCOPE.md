# SCOPE — 确立独立解题与结果导向的工作准则

## 本工单做什么
把用户 2026-11-13 的明确要求（遇到问题先自己想办法解决；不把过程/求助抛给人；只有真阻塞才升级；交付只给「结果 + 方案」）固化为**常驻、可执行的工作准则**：
- 先查重：确认 `~/.dsh/AGENTS.md`、`~/.dsh/LESSONS.md`、memory、superagent 仓库既有规则是否已覆盖；
- 把准则写入唯一权威源（全局规则 → `~/.dsh/AGENTS.md`；仓库内行为规范 → dsh-superagent-playground 相应文档），并配可执行的判据/检查，避免只剩口号；
- 附验证：按新准则自检（排障证据、升级门槛、交付形态）能实际命中。

## 不做什么
- 不改 dsh-superagent 运行代码/提示词实现（除非核查证明准则只能落在那里才需要单独确认）；
- 不重复已有条目（查重命中则更新既有条目，不新增平行叙事）；
- 不动无关分支、不删除工单目录。
