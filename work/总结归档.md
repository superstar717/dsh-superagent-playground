## 二、核心结论速览

### 三大"X-Anything"主角
- **craft-anything**（storytold/ArtCraft，Rust，19.4k★，MIT/Apache-2.0 双许可）：应用级逆向——看懂任意软件再让编码 agent 复刻；320 检查工具、Clean-room/Deep 双模式、桌面 app+CLI+MCP；2026-10-31 创建、周更 5 版（v0.5.0）、极活跃但自认 early alpha；团队背景无官方信息。
- **cli-anything**（HKUDS，Python，58.4k★，Apache-2.0，arXiv:2606.03854）：把有源码的软件自动生成为 agent 可用 CLI；7 阶段流水线 + CLI-Hub（40+ 现成 CLI）；2026-03 创建，但最后 release 2026-06-25、最后提交 2026-09-22，已放缓。
- **REA**（morluto/rea，TypeScript，**439,531★**/108,852 forks，MIT）：新兴层头部——"One MCP for reverse engineering across binaries, applications, and runtime behavior"，207 个 MCP 工具接原生二进制/JS-Electron/.NET/网站，可调 Hopper/Ghidra/IDA/Kuna；`npx rea-agents setup`，官网 rea.tools；**只从官方三源获取**（README 自带防伪警告，存在描述相同的拷贝仓）。
- 三者关系：craft 与 REA 同赛道（看懂并复刻）、craft 与 cli-anything 互补（复刻新软件 vs 驱动现有软件）；均无官方关联。

### 传统逆向工具（速记）
Ghidra（98.5k★/Apache-2.0，静态事实标准）· Frida（22.7k★，动态插桩事实标准）· x64dbg（50.2k★，Windows 用户态）· jadx+Apktool+MobSF（Android）· binwalk+FirmAE（固件/IoT）· Wireshark+mitmproxy（协议）· angr/capstone/Unicorn/Qiling/LIEF（自动化库）。选型速查表见报告§三。

### AI 逆向 agent 新兴层（报告§16）
Integuru（4.8k★/AGPL，逆向平台内部 API，开源为 v0 快照已转商业）、ctf-skills（3.6k★/MIT）、jshookmcp（2.1k★/AGPL）、Seep-Reverse-Lab（2.1k★/GPL）、cheatengine-mcp-bridge（1.8k★/MIT）、open-reverselab（1.3k★/GPL，Sentry 赞助）、Rikugan（707★/MIT，IDA/BinaryNinja）、android-reverse-engineering-skill（8.7k★/Apache-2.0）；DSH 生态有 dsh-rea、dsh-craft-anything、QNX-Agent、ghidra-skill-for-dsh。特点：2026 年新建为主、单作者多、部分无许可；当"效率外挂"用，AGPL/GPL 注意传染性。
