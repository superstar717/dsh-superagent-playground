# 方法论工作台（姜胡说 × 李公子）

把两位博主已提炼的「系统 / 框架 / 方法论」陈列在一个本地网页里，方便浏览与查阅。
本目录是 dsh-superagent 工单 `methodology-workbench` 的源码；成品是自包含单文件页面。

## 打开方式

双击打开（或浏览器打开）：

```
~/methodology-workbench/index.html
```

离线可用、无需起服务。深度问答/全量图谱在 GraphMind（http://localhost:8777，需已启动）。

## 页面内容

- **总览**：两位博主卡片（视频数 / 字数 / 框架数 / 图谱规模）
- **姜胡说**：体系总览 10 节（总框架、核心公式、三大底层思维、五步方法论、金句 30、失败模式、30 天行动地图、自检 10 问等）+ 九大主题全文
- **李公子**：9 个框架（每条标注出处视频，可点开本机转写原文）+ 知识金字塔详解
- **知识图谱**：两个 LightRAG 图谱数据集的核心子图（力导向、类型着色、搜索聚焦、节点详情带出处文件）
- **检索**：跨两位博主全部内容的即时搜索
- **数据与口径**：来源清单、重建命令、口径与边界（诚实说明）

## 构建

只读消费既有数据，不改任何源文件：

```bash
python3 build.py   # 重新生成 ~/methodology-workbench/index.html
```

数据源（均为只读）：

| 内容 | 路径 |
|---|---|
| 姜胡说知识库 | `~/姜胡说/kb/`（SYSTEM + INDEX + 9 主题，源自 544 视频） |
| 姜胡说转写原文 | `~/姜胡说/asr/` |
| 李公子框架文档 | `~/李公子/框架体系汇总-详细版.md`、`知识金字塔-详细梳理.md` |
| 李公子转写原文 | `~/graphmind-replica/data/ligongzi_9c54ca/input/`（228 条） |
| 图谱数据集 | `~/graphmind-replica/data/{ligongzi_9c54ca, jianghushu-methodology_b0607c}`（LightRAG graphml） |

## 边界（诚实说明）

- 出处链接指向本机转写原文（file://），文件移动或改名后失效；定位不到的条目以灰色标注。
- 转写为语音识别结果，存在同音误差（如「挨打模型」≈ AIDA），李公子文档内附勘误表。
- 图谱页为核心子图（按关联度取前 N，默认 420）；全量图谱与向量检索走 GraphMind。
- 只展示博主的提炼成果，不含我方应用方案（如金字塔结构层 v1.1 计划，状态见 `~/李公子/SCOPE.txt`）。
- 统计口径以 `kb/INDEX.md` 为准（544 视频 / ASR 100%；SYSTEM.md 文头的 542 为早期口径）。
